# Streamlit - Aula 1

Atividade de introdução ao Streamlit.

## Como executar

```bash
pip install streamlit
pip install pandas
python -m streamlit run app.py
```

## Conteúdo da atividade

- "Olá, mundo"
- Variáveis com nome e idade
- DataFrame com Português, Matemática, Python e Frame
- Título "Meu primeiro dash"
- Subtítulo com o nome Sofia
- Registros das telas da atividade
